# STEDI Human Balance Analytics Project - Data Analytics at Scale

A WGU/Udacity project for D609 Data Analytics at Scale
Project is built on AWS utilizing S3, Glue, Glue Data Catalog, and Athena. 
We have raw JSON landing in S3, then its filtered into trusted tables and is then joined into curated tables for machine learning. 

# All row counts match the provided project rubric

## Notes: 
- Source nodes: `customer_landing_to_trusted` reads the customer landing zone with an Amazon S3 source node. 
- The other four jobs (`accelerometer_landing_to_trusted`, `customer_trusted_to_curated`, `step_trainer_trusted`, `machine_learning_curated`) use AWS Glue Data Catalog source nodes, which point at the same S3 landing, trusted, and curated folders.
- I did this following the project hint from the rubric that recommends the Data Catalog source node over the S3 bucket node, which can sometimes extract incomplete data. Row counts for every table match the rubric.
- All the Python scripts were generated by Glue Studio, as I built each job using the visual editor which generated the PySpark scripts.
